QUESTION HANDLING
  Answer the question asked in one or two sentences, then offer the backup.
  Place the answer at one of three layers: the observation model (what the
  events or coefficients supply), the theorem (what holds for the stated
  estimator under its hypotheses), or the benchmark (what the full method
  returns on its scored population).
  When a step is challenged: ask for the equation or proposition, name the
  hypotheses it uses, then give the argument. If the step needs checking,
  state the intended argument and its hypotheses and offer to follow up.
  Rehearsal answers with follow-ups: ../misc_ideas_feedback/defense_probing_q&a.md.

SCRIPT
  Ordinary paragraphs are spoken. Headings, likely questions, and bracketed
  italic instructions organize rehearsal and remain silent.
  Each substantive backup has an answer and an 'If asked for more' explanation.
  The main talk is about 5,870 words; 47–53 minutes before pauses at 110–125 wpm.
  Time the actual rehearsal. Backup answers are outside the main-talk estimate.

EDIT AND BUILD
  Edit core.tex / backup.tex for slides and embedded notes.
  Edit defense-script.md for full spoken prose; keep its titles and numbering
  aligned with the deck. build_script.py checks this alignment.
  Run make check, then make all from this directory. All TeX intermediates are
  built in /tmp. Root PDFs, source-map.csv, and source-snapshot.sha256 refresh.
  Footers and [n] citations use the bundled thesis-references.json snapshot. After thesis
  edits, run ../dissertation_format_rules/recheck.sh, then make refs with
  THESIS_BUILD=/path/to/that/fresh/build, then make all. Missing or stale
  references stop the build. See README for the full reference workflow.
  See README.md for validation commands and the fresh-session entry point.

ZOOM WITH SYNCHRONIZED FULL SCRIPT (LINUX, TWO SCREENS)
  Install Pympress and its video backend; Ubuntu commands are in README.md.
  Build: make presenter PYTHON=/usr/bin/python3
  Start: pympress --notes=after defense-presenter.pdf
  Use an extended desktop. Keep the presenter window private and share only
  the audience window in Zoom. S swaps screens. Next/previous slide actions
  advance the full script with the slide, including backup slides.
  The script is shown a page at a time; enlarge the notes pane for reading.
  Click slide 17's panels to play the linked, looping MP4s. Keep both videos
  in figures/aperture when moving the PDF. Rehearse playback and Zoom sharing
  on the actual presentation computer. Distribute defense.pdf to the audience;
  defense-presenter.pdf also contains the private full script.

  The full script appears in the large presenter pane. N toggles notes mode.
  If updating an already-open presenter PDF, close both Pympress windows and
  reopen it. The builder uses script: page labels for grouped notes; notes:
  labels select Pympress's different, interleaved layout and hide the script.
